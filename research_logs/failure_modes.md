# 负结果失败模式分类学（R122）

把「20+ 静态第 4 组件候选全否 + 6 个可学习结构 baseline 全败」升级为「5 类失败模式 + 3 条可复用机制规律」。

## 失败模式

- **模式 A：噪声幅值重分布（不增总扰动预算）**。对称 iid 嵌入噪声 ε=0.2 的释秩已饱和：按度/深度/side/epoch 重排同一扰动预算，只是「换一种方式花同一笔钱」，峰值不涨（R16 ε 平坦 + R20/R28/R31/R33/R58 中性 + R30 锐化有害）。
- **模式 B：主分支显式抗过平滑（噪声已释秩后冗余）**。噪声已把过平滑压到 0.003（E11），主分支再加 dropout/初始残差/层聚合/DropEdge 皆冗余，其中层聚合 −2.5% 说明「显式抗过平滑」甚至会稀释已释秩的主表征。
- **模式 C：破坏 BPR 内积「方向+范数」几何（范数=流行度信号）**。BPR 排序依赖「方向+范数」两部分，范数编码 degree/流行度置信度（KDD'25 权重衰减视角 + KDD'26 向量分解 + R23 消融三路互证）。抹掉范数（余弦评分）或显式摊平谱（谱平衡）都破坏排序。
- **模式 D：优化器/训练细节（通用技巧，落 seed 噪声带）**。多负例/学习率调度/SWA/weight-decay/margin/初始化缩放等通用训练技巧，在本骨干上无一产生超出 gowalla seed 噪声 ±0.0008 的决定性增益——增益被噪声 SSL 的强成形吸收（R93 9 run 实测）。
- **模式 E：可学习结构（关停传播自由度 / 慢收敛 / 全局信号拉平）**。可学习结构给了模型「关停 GCN 以平凡最小化 InfoNCE」的自由度（R19 门控把 InfoNCE 1.14→0.14），或慢收敛（NGCF ep338 才达峰、DCCF/AdaGCL 慢收敛），或全局/低秩信号拉平个性化（LightGCL/HCCF）。官方超参下 6 个可学习结构 baseline 全部远低于静态三组件融合。

## 可复用机制规律

1. 唯一必要且充分的增广 = 对称 iid 嵌入噪声（在传播过程中逐层注入）——它在「路径」上打破秩塌缩，而非在「最终表征」上用损失项推回（2610.09958 跨架构佐证：depth-induced rank collapse 只有静态路径修复能重开）。
2. BPR 内积的「方向+范数」几何是排序目标的不可侵犯约束——范数编码流行度信号，任何抹除/摊平/重标定范数的改动（R23/R35）都与排序目标冲突，除非重标定严格向 log(degree+2) 相对先验去噪（R118/R119，待测）。
3. 静态改动的价值上限 = 噪声已提供的隐式正则——显式正则（R25/R34/R38/R39/R49）与优化器细节（R37/R40/R41/R60）在噪声 SSL 已提供强隐式正则后冗余，增益落 seed 噪声带。
