# 基于图神经网络的稀疏协同过滤推荐方法

> 毕业论文项目 · 完整实验数据与可复现代码

## 项目简介

在 LightGCN 骨干上叠加 **3 个静态无参组件 + 1 个条件语义组件**，三核心数据集 Recall@20 相对官方超参 baseline 提升 **+3.5% ~ +43.3%**，13 数据集泛化验证稀疏图稳健受益。机制为"噪声抗过平滑 + 释放嵌入秩"，适用边界由图密度（ρ≈3.42%）定量刻画，**零额外参数、27.6× 收敛加速**。

---

## 一、融合模型（4 组件）

| 组件 | 做法 | 配置 | 作用 |
|---|---|---|---|
| ① 嵌入噪声增广 | 逐层单位球方向扰动 `x+ε·sign(x)`，双视图对比 | ε=0.2 | 抗过平滑 + 释放嵌入秩 |
| ② SSL 固定窗口退火 | SSL 权重 cosine 衰减到 0，后半程纯 BPR 精调 | W=30, λmax=0.1 | 消除峰后过拟合 |
| ③ 容量缩放 | 嵌入维度 64→512 | d=512 | 释放容量瓶颈（须配①协同） |
| ④ 冻结语义注入 | LLM 编码物品文本，冻结加权注入 `e_id+λ·e_llm` | λsem=2.0 | 补冷启动（仅文本富集集） |

| 组件 | 数据集 | 独立增益 | 显著性 |
|---|---|---|---|
| ① 嵌入噪声增广 | gowalla | **+6.7%**（0.1762→0.1882） | p<0.001，零交叉 ✅ |

## 六、机制证明（E11 底层实验）

| 度量 | 纯 LightGCN | 融合（加噪声） | 含义 |
|---|---|---|---|
| 有效秩（128 维） | 53/128（41%） | 124/128（**97%**） | 噪声释放嵌入容量 |
| 过平滑 | 0.033 | **0.003（11×↓）** | 表征不再塌缩到均值 |
| 层间余弦 cos(l0,lL) | 0.70 | 0.46 | 层间不再过度相似 |

**跨数据集复证**：lastfm-2k 上噪声同样 2.84× 释秩 + 1.74× 抗过平滑；ml-1m（稠密）噪声释秩但无过平滑可抗 → 释秩≠增益（机制级边界证据）。

## 九、复现方法

```bash
# 环境
conda create -n sgl python=3.9 && conda activate sgl && pip install -r requirements.txt

# 融合模型（三核心数据集）
python main.py --recommender=NoiseSGL --dataset=gowalla --embed_size=512 \
  --view_mix=nn --noise_eps=0.2 --ssl_anneal=2 --ssl_anneal_epochs=30

# baseline（官方超参，见各模型分支）
bash research_logs/run_baselines_official.sh <gpu_id> <baseline_name>
```
